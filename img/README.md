# Фотографии портфолио

Положите сюда настоящие фото с **точно такими именами** — код менять не нужно:

| Объект | Файлы |
|---|---|
| ЖК Caravan Avenue | `caravan-avenue-1.jpg`, `caravan-avenue-2.jpg`, `caravan-avenue-3.jpg` |
| ЖК EcoSmartHome | `ecosmarthome-1.jpg`, `ecosmarthome-2.jpg`, `ecosmarthome-3.jpg` |

- Формат JPG, горизонтальные, соотношение сторон около 4:3 (кадр обрезается по центру).
- Ширина 1600 px достаточно; старайтесь уложиться в 300 КБ на фото.
- Первое фото (`-1`) на телефоне показывается крупно.
- Пока файла нет, на его месте рисуется заглушка с подписью.

Список объектов и число фото задаются в `bot/steps.py` (`PORTFOLIO`); после правки
запустите `python scripts/export_steps.py`.

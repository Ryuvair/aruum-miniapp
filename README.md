# Mini App ARUUM STUDIO

Статическая страница без сборщиков: `index.html`, `styles.css`, `app.js`, `steps.json`, `img/`.
Её можно выложить на любой HTTPS-хостинг; ниже — GitHub Pages.

## Как это работает

1. Бот после выбора языка присылает кнопку под полем ввода
   «Посмотреть работы и рассчитать ремонт». Она открывает эту страницу с `?lang=ru|uz`.
2. Пользователь проходит мастер, смотрит портфолио и нажимает «Отправить заявку».
3. Страница вызывает `Telegram.WebApp.sendData(...)` — Telegram передаёт ответы боту
   служебным сообщением и закрывает приложение. Сервер для этого не нужен: бот получает
   данные обычным long polling с вашего ноутбука.
4. Бот проверяет данные, сохраняет лид (`mode = miniapp`) и просит контакт кнопкой.

`sendData` работает **только** при запуске с кнопки клавиатуры в чате. Если открыть страницу
по прямой ссылке или из меню бота, анкета пройдётся, но заявка не отправится.

## Публикация на GitHub Pages

1. Создайте на github.com новый **публичный** репозиторий, например `aruum-miniapp`.
2. Загрузите в него **содержимое папки `miniapp/`** (сами файлы, а не папку целиком), так,
   чтобы `index.html` лежал в корне репозитория. Через сайт: *Add file → Upload files*,
   перетащить `index.html`, `styles.css`, `app.js`, `steps.json` и папку `img`.
   Или из командной строки (из корня проекта):
   ```
   cd miniapp
   git init -b main
   git add .
   git commit -m "feat: ARUUM mini app"
   git remote add origin https://github.com/<логин>/aruum-miniapp.git
   git push -u origin main
   ```
3. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)`, **Save**.
4. Через 1–2 минуты страница откроется по адресу `https://<логин>.github.io/aruum-miniapp/`.
   Откройте его в браузере: должен появиться экран приветствия.

В репозитории не должно быть `.env`, базы и логов — в папке `miniapp/` их нет.

## Подключение к боту

1. В файле `.env` в корне проекта добавьте строку (со слэшем на конце):
   ```
   MINIAPP_URL=https://<логин>.github.io/aruum-miniapp/
   ```
2. Перезапустите бота (`run.bat`). В логе появится `miniapp=on`.
3. В Telegram отправьте `/start`, выберите язык — под полем ввода появится кнопка
   «Посмотреть работы и рассчитать ремонт».

В @BotFather ничего настраивать **не обязательно**: кнопку с адресом присылает сам бот.
По желанию можно выполнить `/setdomain` или завести Main Mini App (`/newapp`), но запуск
оттуда не умеет `sendData`, то есть заявку так отправить нельзя.

## Фотографии

Положите файлы в `img/` с именами из `img/README.md` и загрузите их в репозиторий —
заглушки заменятся сами.

## Изменение шагов и текстов

Тексты и шаги не редактируются в этой папке. Источник — `bot/steps.py`:

```
.venv\Scripts\python scripts\export_steps.py
```

Команда пересоберёт `miniapp/steps.json`; после этого загрузите его в репозиторий
и перезапустите бота, чтобы обе стороны знали одни и те же варианты.

## Локальный просмотр

```
.venv\Scripts\python -m http.server 8765 --bind 127.0.0.1 --directory miniapp
```

Откройте <http://127.0.0.1:8765/?lang=ru>. Вне Telegram вместо нативной кнопки показывается
её замена, а отправленные данные пишутся в консоль браузера. Параметры для просмотра:
`?lang=uz`, `?scheme=light`, `?screen=wizard&step=1`, `?screen=portfolio`, `?screen=summary`.

Скриншоты на всех размерах (при запущенном сервере):

```
.venv\Scripts\python scripts\make_screenshots.py
```
